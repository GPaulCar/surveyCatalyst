This workspace is the authoritative area for optimization work and artifacts.

Execution model:

1. Assess

3. Execute
4. Validate
5. Monitor

Rules:

- Assessment tasks are read-only unless explicitly marked otherwise.
- Use `assessment/registry.json` as the single source of truth for execution order and task status.
